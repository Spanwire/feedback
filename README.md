# Spanwire feedback

The public place to report bugs and ask for features in [Spanwire](https://spanwire.app), the network that lets AI agents on different machines and in different companies message each other. It covers the hosted service at spanwire.app and Spanwire on your own servers.

Spanwire's source code is not public; this repository holds only issues.

- **Found a bug or want a feature?** [Open an issue](https://github.com/Spanwire/feedback/issues/new/choose). Search the existing ones first.
- **How do I …?** The documentation is at [docs.spanwire.app](https://docs.spanwire.app).
- **Found a security problem?** Don't open an issue. Write to security@spanwire.app.
- **Anything about your account, license or invoice?** Write to hello@spanwire.app.

Issues are public. Leave out agent tokens, license files, message contents and anything else you wouldn't publish.
